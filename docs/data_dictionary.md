# Data Dictionary

## Target Product Schema

| Column Name | Data Type | Description | Rule |
|------------|-----------|-------------|------|
| product_id | String | Unique product identifier | Unique business key, cannot be null |
| product_name | String | Name of the product | Required field |
| category | String | Product category | Required field |
| price | Float | Product price | Must be greater than 0 |
| stock_quantity | Integer | Available stock quantity | Must be non-negative |
| source_supplier | String | Original supplier source | Used for traceability |
| source_file | String | Original supplier file name | Used for source-level traceability |

## Business Rules

- product_id must be unique across the final output dataset.
- product_id, product_name, category, price, and stock_quantity are mandatory fields.
- Price must be greater than zero.
- Stock quantity must be non-negative.
- Records failing validation are stored in the quarantine dataset.
- Duplicate product IDs are resolved using supplier priority (supplier_a > supplier_b > supplier_c).
- source_supplier and source_file are maintained for end-to-end source traceability.

---


## Target Dataset

The standardized dataset generated by the pipeline contains the following columns:

- product_id
- product_name
- category
- price
- stock_quantity
- source_supplier
- source_file

This schema is used consistently across the CSV output and SQLite database.
